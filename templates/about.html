About CodeSentry

A code review and vulnerability scanner that explains every risk it finds.

{% endblock %} {% block body %}

What it does

CodeSentry reads source code you paste or upload and checks it for common security flaws. For each issue it shows the exact line, why it is dangerous, how to fix it, and the CWE and OWASP reference. The result is a security score from 0 to 100 and a grade from A to F, with the vulnerable lines highlighted in a source viewer.

It is built for students and developers who want a fast first security review of their own code before it reaches GitHub or production.

1

Submit code

Paste it or drag in a file. The language is detected automatically, or you can choose it.

2

Analyse

Python is parsed into a syntax tree (AST) so checks follow real code structure. JavaScript, PHP and secrets use pattern rules.

3

Review

Browse findings by severity, jump to the line, export JSON, print the report, or ask AI for a second opinion.

How the score works

The score starts at 100. Each finding subtracts points by severity: Critical 25, High 15, Medium 7, Low 3. A is 90 and above, B 75 and above, C 60 and above, D 40 and above, and F below 40.

Privacy and safety

Your code is only read, never executed. Scans are stored in a local SQLite database on the machine running the app, and you can delete any report. The optional AI review sends the code to the AI provider only when you press the button and have set an API key.

Known limitations

Static analysis has false positives and cannot understand business logic, so it will not find a broken login flow or a missing permission check. Use it as a first pass, then review by hand. {{ n }} rules are covered today, and new ones are easy to add in scanner.py.

Key features

  • Python AST analysis, so checks follow real code structure instead of plain text matching
  • {{ n }} detection rules mapped to CWE and the OWASP Top 10
  • Security score from 0 to 100 with an A to F grade
  • Source viewer with the vulnerable lines highlighted and linked to each finding
  • JSON export, print-ready reports and a full scan history
  • Optional AI review for logic and authentication issues the rules cannot see

Built as an MCA project to practise secure coding, static analysis and full-stack development.
